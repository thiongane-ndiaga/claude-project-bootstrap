# 9. Architecture decisions

> The important, costly or risky decisions, and their justification.

Decisions are recorded as ADRs managed with Archgate, in
[`docs/architecture/adrs/`](../adrs/). This section does not copy them.

- List ADRs: `archgate adr list`
- Read an ADR: `archgate adr show ARCH-NNN`
- Create an ADR: `archgate adr create --title "…" --domain architecture`

Guiding questions:
- Which decisions are still "Proposed" and waiting to be settled?
- Which decisions have been superseded, and by what?
