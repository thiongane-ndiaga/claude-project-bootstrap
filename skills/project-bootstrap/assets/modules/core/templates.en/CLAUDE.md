## Rules
@@module:openspec
- Any behavior change goes through an OpenSpec change.
- Never edit `.claude/skills/openspec-*` or `.claude/commands/opsx/` (regenerated by `openspec update`).
@@end
@@module:archgate
- Never edit `rules.d.ts` (regenerated by Archgate).
- ADR: `archgate adr create --title "…" --domain <domain>`, then check that `rules:` in the
  frontmatter matches the presence of a `.rules.ts` (the CLI sometimes writes `rules: false` wrongly).
@@end
@@module:claude
- Before declaring a task done: `node .claude/hooks/quality-gate.mjs`.
@@end
@@module:github
- `gh` commands that write (issue/pr/release create, merge) always ask the user for approval.
@@end
