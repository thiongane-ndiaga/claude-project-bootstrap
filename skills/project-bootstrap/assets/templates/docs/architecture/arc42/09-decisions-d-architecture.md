# 9. Décisions d'architecture

> Les décisions importantes, coûteuses ou risquées, et leur justification.

Les décisions sont consignées sous forme d'ADR gérés avec Archgate, dans
[`docs/architecture/adrs/`](../adrs/). Cette section ne les recopie pas.

- Lister les ADR : `archgate adr list`
- Lire un ADR : `archgate adr show ARCH-NNN`
- Créer un ADR : `archgate adr create --title "…" --domain architecture`

Questions-guides :
- Quelles décisions sont encore au statut « Proposé » et attendent d'être tranchées ?
- Quelles décisions ont été remplacées, et par quoi ?
